## Which file do I download?

| file | who it is for | what it does |
|---|---|---|
| `transcript-normalizer-VERSION-<system>-lite` | anyone who just wants to use it | fetches the platform's captions and fixes domain terms; opens a menu when double-clicked |
| `transcript-normalizer-VERSION-<system>-full` | anyone who also has videos without captions, or audio files | everything lite does, and also transcribes audio on your computer (the first time, it downloads a 1.5 GB speech model) |
| `transcript_normalizer-VERSION-py3-none-any.whl`, `.tar.gz` | Python developers | the package, for `pip install` |

`<system>` is `windows`, `macos` (Apple silicon) or `linux`. The executables are not signed, so Windows and macOS will warn the first time; the SHA-256 of every file is at the end of this page.

## Qual arquivo baixar?

| arquivo | para quem | o que faz |
|---|---|---|
| `transcript-normalizer-VERSION-<sistema>-lite` | quem só quer usar | pega a legenda da plataforma e corrige os termos da área; abre um menu com dois cliques |
| `transcript-normalizer-VERSION-<sistema>-full` | quem também tem vídeos sem legenda, ou arquivos de áudio | tudo o que o lite faz, e ainda transcreve o áudio no seu computador (na primeira vez, baixa um modelo de fala de 1,5 GB) |
| `transcript_normalizer-VERSION-py3-none-any.whl`, `.tar.gz` | quem programa em Python | o pacote, para `pip install` |

`<sistema>` é `windows`, `macos` (Apple Silicon) ou `linux`. Os executáveis não são assinados, então o Windows e o macOS avisam na primeira vez; o SHA-256 de cada arquivo está no fim desta página.
